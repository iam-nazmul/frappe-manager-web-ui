Password logins aren't supported. The key must not need a passphrase, or must be loaded in ssh-agent.

Connecting checks SSH, Docker and Docker Compose on the server. The first connection trusts the server's host key and remembers it.

Server requirements

  1. Docker Engine and the Compose plugin installed.
  2. The SSH user is in the docker group: sudo usermod -aG docker <user>, then log in again.
  3. This machine's public key is in ~/.ssh/authorized_keys of that user.
