Used once to add this app's key to ~/.ssh/authorized_keys on the server. The password isn't saved.
The key must not need a passphrase, or must be loaded in ssh-agent.

Connecting checks SSH, Docker and Docker Compose on the server. The first connection trusts the server's host key and remembers it.

Server requirements

  1. Docker Engine and the Compose plugin, with the SSH user in the docker group. With password login the UI can set this up for you (the user needs sudo).
  2. Password login allowed (once, to install the key), or a public key already in ~/.ssh/authorized_keys.
